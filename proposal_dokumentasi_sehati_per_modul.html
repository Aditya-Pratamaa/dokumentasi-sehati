SEHATI - Proposal & Dokumentasi Pendahuluan

Ringkasan Eksekutif

Program Makan Bergizi Gratis (MBG) berskala nasional menuntut standarisasi kualitas masakan, ketepatan waktu distribusi, dan akuntabilitas anggaran yang sangat tinggi. Tantangan terbesar di lapangan meliputi koordinasi kru dapur yang tersebar, manajemen stok bahan baku basah/kering, kepatuhan kebersihan, serta transparansi absensi dan penggajian staf.

SEHATI (Sistem Evaluasi HR & Administrasi Terintegrasi) dirancang khusus sebagai Single Source of Truth untuk menjawab tantangan tersebut. Dengan mengintegrasikan sistem HRIS tradisional dengan fitur dapur pintar dan rantai pasok terdistribusi, SEHATI memastikan bahwa seluruh proses produksi berjalan efisien, aman, dan dapat diaudit secara real-time.

Pilar Utama Ekosistem SEHATI:
  • Akurasi & Integritas: Validasi absensi dengan GPS Radius ganda untuk mencegah manipulasi.
  • Efisiensi Operasional: Perencanaan rotasi menu otomatis yang terhubung ke kebutuhan bahan baku.
  • Kepatuhan SOP: Digitalisasi lembar kebersihan dan persiapan untuk audit berkala.
  • Automasi Finansial: Kalkulasi slip gaji otomatis terhubung dengan jam kerja dan PPh21.

Arsitektur Clean Architecture

Untuk menjamin keandalan jangka panjang, skalabilitas tinggi, serta kemudahan dalam integrasi masa depan, SEHATI dibangun sepenuhnya menggunakan prinsip Clean Architecture. Pemisahan kode yang bersih memastikan logika bisnis tidak terikat pada framework UI, database, atau library networking luar.

Presentation Layer
Menggunakan Flutter Web & GetX. Bertugas mengelola rendering UI yang responsif, manajemen state yang reaktif, serta navigasi/routing yang dinamis tanpa membebani memori web browser.
Domain Layer
Merupakan jantung logika bisnis (Core Business Rules). Terdiri dari Entities dan Use Cases yang independen. Tidak terpengaruh perubahan struktur database maupun perubahan desain antarmuka.
Data Layer
Mengelola pengambilan data dari REST API (menggunakan client Dio) dan penyimpanan lokal (GetStorage). Mengimplementasikan Repository Pattern untuk transisi data.
Modular Features
Setiap modul (Auth, Absensi, Dapur, Payroll, Stok) diisolasi dalam satu folder fitur yang berisi struktur data, domain, dan presentasi tersendiri guna mempermudah kolaborasi tim developer.
Teknologi Pendukung Utama:
• Framework: Flutter Web SDK 3.x • State Management: GetX
• Networking: Dio Client • Storage: GetStorage • Laporan: Excel (xlsx) & PDF Export
